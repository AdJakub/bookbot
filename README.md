# bookbot

BookBot started out as my project for the boot.dev curicculum, where it was just a simple word and character counter in a text. Over the course of terra i already fleshed it out so much more though! I have added a simple Sentence Boundary disamiguator made from scratch (didnt want to use punkt or anything, part of the learning experience :) ) a simple syllable counter, and a readability score calculator!
